How it would run

A new set every Tuesday

The deal builds the set. The week's skin decides the floor (checks, xerox crosshatch, concrete, paint, notebook paper…), the giant backdrop behind everything (a sun, a flame wall, the week's number in stacked xerox numerals, the odds written in marker), the inks on the towers and the wordmark's face.

The high points run along the top. The strip over the set is a ticker of the week's other numbers: the Game of the Week, the worst bench, the luckiest win.

The towers stay honest. They are the live playoff sim, labelled in the week's black boxes. In this mock every week shows today's odds; on Home it is always the current week, so the odds are always live.

The star is the only full-size print. Everyone else is a face on a tower.

Past weeks stay flat; one live 3D set per page is enough for a phone. Drag turns the camera, double-tap replays the build, and reduced motion shows the finished frame.
